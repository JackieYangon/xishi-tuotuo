# 实现架构

更新：2026-11-11。

- 前端：原生 JavaScript、WXML、WXSS。6 个页面：婚礼首页、家庭群组、通用管理、圆桌排座、电子请柬、导出。通用管理根据 type 展示事项、物品、商家、宾客、流程、住宿。
- `utils/service.js` 等待云初始化后调用云函数；云环境自有时使用 wx.cloud，共享时配置资源方并创建 wx.cloud.Cloud。缓存只保存当前会话数据，本地存储仅记当前群组 ID。
- 云函数 `xishiTuotuoApi`，集合 `xishi_tuotuo_groups`，存储前缀 `xishi-tuotuo/`。单群组文档管理关联数组，事务与 revision 校验防止丢失更新。表单必须固定编辑时版本；冲突草稿不可自动升级版本重试。
- 服务端以运行上下文 APPID/OPENID，或成对的 FROM_APPID/FROM_OPENID 校验来源；本地 allowedAppId 只允许当前小程序。数据库权限要求仅管理员可读写。
- 群组邀请码 7 天有效，群主可旋转与移除成员。亲友请柬使用独立随机令牌，不返回内部成员、电话、内部备注或其他宾客。
- 回执人数增加超过原桌容量时取消原排座并提醒；内部 note 与亲友 replyNote 分离。
- 照片和音乐通过受权限校验的云函数上传，注册后才能绑定请柬；不修改共享环境存储规则。
- 导出器独立实现 OOXML/ZIP，无前端第三方依赖。字段白名单导出，电话与备注默认关闭，不输出身份或令牌。
- `package.json` 是版本唯一来源；本地 setup 生成版本模块、微信项目配置及云配置，生成文件不进入 Git。
