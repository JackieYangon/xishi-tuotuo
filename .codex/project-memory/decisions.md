# 产品决策

更新：2026-11-11。来源：用户本轮确认。

- 产品名称喜事妥妥，微信原生小程序，云开发存储和协作。
- 筹备进度 = 已完成备婚事项 / 全部备婚事项，四舍五入为整数百分比；无事项为 0%。物品完成不重复计入。
- 协作对象是家庭群组，包含新人、父母和其他帮忙的家人，群组成员共同编辑。
- 保留婚礼档案、事项、物品、商家联系及报价、宾客、请柬、回执、圆桌、当天流程、住宿、导出。
- 圆桌必须提供 10 人桌、12 人桌、自定义三种选择；当前自定义范围 1–30 人，同一家庭按同行人数整组占座。
- 不包含预算账本、礼金簿、婚车、多场次、灵感收藏、共享相册；每个群组一场婚礼。
- 官方模板全部移除，不保留示例页面、图片、组件、快速入门函数或脚本。
- 云环境与另一小程序共用，必须使用独立命名，不调整其他项目资源或全环境安全规则。
- 默认中文，README 双语互链，Git 提交信息仅英文；所有日常提交推送指定仓库 main。
- 初始版本 0.1.0，之后遵循重大升级/功能新增/修复对应主/次/修订版本规则。
